# Glossary

The words Country Badge Generator and its code use for one thing each.

| Term       | Definition                                                                                          | Do not write          |
| :--------- | :-------------------------------------------------------------------------------------------------- | :-------------------- |
| Badge      | The square 1024 × 1024 image the app exports: a country's flag on one background.                   | icon, avatar, sticker |
| Background | One of the three deterministic, flag-inspired fills a Badge can use, derived from the fetched flag. | theme, style          |
| Palette    | The three Backgrounds offered for one country, shown as options before export.                      | colors, swatches      |
| Country    | One supported entry of the pinned country data, found by name, code or alternate spelling.          | nation, region        |
| Export     | A downloaded SVG, PNG or JPG of the current Badge, or its SVG markup copied to the clipboard.       | save, render          |
